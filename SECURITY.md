# Security Policy

## Supported Versions

The following versions of **Telegram AI Content Pipeline** currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project and user data seriously. If you discover a security vulnerability, please do **NOT** open a public issue or discuss it in public chat channels.

Instead, please report security vulnerabilities responsibly:

1. **GitHub Security Advisory (Preferred)**:
   Navigate to the repository's [Security Tab](https://github.com/Mahdi-Soleimani/telegram-ai-content-pipeline/security) and click **"Report a vulnerability"**. This allows confidential triage and resolution.
2. **Direct Contact**:
   Reach out directly to the maintainer via GitHub profile messaging at [@Mahdi-Soleimani](https://github.com/Mahdi-Soleimani).

### Information to Include in Your Report
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Any proposed remediation or patches.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for assessing and fixing the issue.
- Once fixed, a security advisory will be published with appropriate attribution (unless you prefer to remain anonymous).

## Responsible Disclosure & Telegram Platform Policies
- This tool is designed for personal content automation and authorized channels. Users are responsible for complying with the [Telegram Terms of Service](https://telegram.org/tos).
- Never share, commit, or expose your `SESSION_STRING`, `API_HASH`, or bot tokens publicly.
